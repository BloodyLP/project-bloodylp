# Bloody Design System (BDS)

Version: 1.0

---

## Philosophie

Nicht Effekte erzeugen Emotionen.

Details erzeugen Emotionen.

---

## Prinzipien

- Jede Animation hat einen Zweck.
- Jede Farbe besitzt eine Bedeutung.
- Jede Card gehört zur selben Familie.
- Weniger ist mehr.
- Persönlichkeit schlägt Perfektion.
- Atmosphäre schlägt Effekte.
- Performance ist ein Feature.
- Konsistenz schlägt Komplexität.
