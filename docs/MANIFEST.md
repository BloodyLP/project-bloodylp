# Bloody Design System

## Warum?

Diese Website ist mehr als eine Homepage.

Sie verbindet zwei Welten:

- BloodyLP
- Alexander Blattmann

Gaming.
Kommentator.
Creator.

---

## Unser Ziel

Nicht möglichst viele Effekte.

Nicht möglichst viele Animationen.

Sondern eine Website, die Vertrauen schafft.

Eine Website, die Persönlichkeit zeigt.

Eine Website, die Menschen verbindet.

---

## Unsere Regeln

- Foundation vor Features.
- Desktop und Mobile sind gleichwertig.
- Jede Komponente ist wiederverwendbar.
- Animation unterstützt Inhalte.
- Konsistenz schlägt Komplexität.
- Qualität schlägt Geschwindigkeit.
