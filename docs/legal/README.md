Die Dokumentation dient ausschließlich der internen Wartung und ist nicht Bestandteil der veröffentlichten Website.

Jede technische Änderung an der Website ist darauf zu prüfen, ob sie Auswirkungen auf

- Datenschutzerklärung
- Impressum

hat.

Erst danach gilt ein Feature als abgeschlossen.
